# Vercel Deploy Checklist

- [ ] Vercel project created from repository.
- [ ] Neon database attached.
- [ ] migrations run successfully.
- [ ] `CKB_RPC_URL` configured.
- [ ] secrets generated with high entropy.
- [ ] `/api/health` passes.
- [ ] `/api/health/rpc` returns network/version information.
- [ ] initial admin/setup path disabled after provisioning or protected.
- [ ] API key created.
- [ ] testnet tx tracked.
- [ ] evidence export succeeds.
- [ ] webhook test succeeds.
- [ ] redeploy during active reconciliation tested.
