# DAO Follow-on Proposal Outline

Prepare only after V1 adoption.

Required evidence before drafting final proposal:

- >= 2 independently maintained applications;
- usage metrics over meaningful period;
- public reliability/failure evidence;
- maintainer/community feedback;
- clear security roadmap;
- evidence of ongoing maintenance capacity.

Possible funded extensions:

- expected Cell assertions;
- multi-RPC failover;
- deeper CKB conflict diagnostics;
- Cellora adapter;
- self-hosted deployment profile;
- external security review;
- stable 1.0 API/SDK.
